# 分镜与文档结构

> 本文件是动画的“剧本结构”：先定章节、节奏、画面和音效，再写代码。
> 配音逐句文案见 [script.md](script.md)（由 `src/script.js` 自动导出，二者永远一致）。

## 总体设计

| 项目 | 决定 |
| --- | --- |
| 时长 | 约 12 分钟，7 个章节、22 个场景 + 6 张章节卡 |
| 画幅 | 1920×1080，SVG 矢量绘制，任意缩放不糊 |
| 主角 | **Claude**（橙色光芒造型，讲解者）、**Ferris**（Rust 螃蟹，提问者） |
| 配角 | **rustc**（齿轮头机器人，编译器本尊）、猫、狗、笼子、生命周期光带、型变之格 |
| 叙事结构 | 提问 → 历史中找答案 → 回到 Rust → 看代码 → 拆编译器 → 回扣开头的问题 |
| 色彩语义 | 协变 <span style="color:#22A06B">绿 `+`</span>、逆变 <span style="color:#3B82F6">蓝 `−`</span>、不变 <span style="color:#E5484D">红 `o`</span>、双变 <span style="color:#8E4EC6">紫 `*`</span>，全片统一 |
| 声音 | 配音（IndexTTS 2.5 预生成，浏览器朗读兜底）+ 程序合成音效 + 程序合成背景音乐 |

### 节奏原则

1. **一句话一个画面动作**：每句配音开始时，画面上必有一个元素出现或变化，观众的眼睛永远有落点。
2. **先具象后抽象**：猫和笼子 → Java 数组 → 生命周期光带 → 代码 → 格与约束表。
3. **伏笔与回收**：第一章“往猫笼里塞狗”的爆炸，在第四章 `&mut` 的悬垂引用处原样重演，让观众自己发现“这是同一个问题”。
4. **呼吸感**：每章之间有 2.5 秒章节卡；重要结论（四种态度、口诀、速查表）停留更久。
5. **情绪曲线**：开场好奇 → 第一章的“翻车” → 第二、三章的豁然开朗 → 第四章的紧张（悬垂引用）与解决 → 第五章的“拆机器”惊喜 → 尾声温暖收束。

## 章节结构

### 开场 · 一个怪现象（约 40s）

| 场景 | 画面 | 音效 |
| --- | --- | --- |
| `op_hook` 螃蟹的困惑 | Ferris 横着跑进画面，头顶冒出代码气泡：`&'static str → &'a str ✓`、`&mut … ✗`（红叉弹出时 Ferris 吓一跳）。Claude 从右上飘入，光芒展开；四个彩色徽章“协变·逆变·不变·双变”依次弹出组成片名。最后一句时一只小猫从画面边缘探头。 | 脚步、弹出、错误嗡鸣、光芒展开的闪烁、片名“叮” |

### 第一章 · 起源：一笼猫，是不是一笼动物？（约 100s）

| 场景 | 画面 | 音效 |
| --- | --- | --- |
| `origin_subtype` 子类型与替换原则 | 一台复古终端显示 `SIMULA 67`，“class / inheritance”字样打出。终端退场，出现 `Animal` 大框，`Cat` 小框落进去，标注 `Cat <: Animal`。Liskov 的“替换原则”以一块铭牌出现，“需要动物”的插槽里放入一只猫，绿灯亮起。 | 打字声、落下的“咚”、通过的“叮” |
| `origin_question` 类型构造器 | 一只猫变成一笼猫，旁边一笼动物，中间一个巨大的问号在弹跳。笼子、列表 `List<_>`、函数 `fn(_)` 三个“外壳”排成一排，内部空位闪烁。箭头示意“里面的关系 → 外面的关系？” | 弹簧声、轻快的提示音 |
| `origin_java` Java 数组的教训 | 一排数组格子，标签从 `Cat[]` 贴上 `Animal[]` 的标签；猫依次被读出，绿勾。Ferris 推进一只狗——警报红灯闪烁、碎片四溅，狗被弹飞（存储被拒绝），`ArrayStoreException` 印章砸下，底部写着“编译期没发现 / 运行时才爆炸”。最后画面分成“读 ↑”“写 ↓”两个方向相反的箭头。 | 读取的“哔”、警报、爆炸、印章 |
| `origin_function` 函数的子类型 | 一份泛黄论文卷轴展开（Cardelli）。中间是一台“函数机器”：入口宽、出口窄。替换者机器入口更宽（接收 Animal）、出口更具体（产出 Cat）。入口箭头变蓝写“逆变”，出口箭头变绿写“协变”。 | 卷轴展开、机器运转、两个音高相反的滑音 |

### 第二章 · 发展：各门语言的驯服之路（约 70s）

| 场景 | 画面 | 音效 |
| --- | --- | --- |
| `dev_langs` 使用处与声明处 | 时间轴从 2004 滑到 2010：`List<Cat>` 与 `List<Animal>` 之间画上红色“≠”。`? extends`（只出不进的单向阀）与 `? super`（只进不出）两个阀门动画。三张语言卡片 C# / Kotlin / Scala 翻开，展示 `out T` / `in T` / `+T -T`。Ferris 用钳子比划“拿出 / 放入”。 | 时间轴滑动、阀门咔哒、卡片翻转 |
| `dev_bivariant` 第四种：双变 | 紫色双向箭头出现。一段 TypeScript 方法参数的例子，两个方向都亮绿灯，但其中一条路上藏着一颗没被发现的“虫子”。 | 双向滑音、虫子的嗡嗡声 |
| `dev_summary` 四种态度 | 四张卡片并排：协变（同向箭头）、逆变（反向箭头）、不变（断开的链条）、双变（双向箭头），每说一个就翻开一个。 | 四声递进的音阶 |

### 第三章 · Rust 登场：生命周期，也是一种关系（约 60s）

| 场景 | 画面 | 音效 |
| --- | --- | --- |
| `rust_noinherit` 没有继承的 Rust | Ferris 翻遍一个写着 `class` 的空箱子，什么都没有。Claude 拉开幕布，露出发光的时间光带。 | 翻找声、幕布拉开 |
| `rust_lifetimes` 活得久，就能顶替 | 一条横贯程序时间线的光带 `'static`，下方一条短光带 `'short` 被包含其中，括号标注 `'long: 'short`。两个引用小卡片沿光带滑动，`&'long T <: &'short T` 打出。Ferris 把“猫/动物”与“长寿/短命”对应起来，左右两组同时高亮。 | 光带“嗡”地展开、对齐的“咔” |

### 第四章 · 四种型变：在代码里看见它们（约 160s，全片重点）

| 场景 | 画面 | 音效 |
| --- | --- | --- |
| `v_covariant` 协变 `&T` | 代码面板逐字打出 `print_it(hello)`；一个 `'static` 引用小卡片沿箭头滑进 `&'a str` 插槽，严丝合缝，绿勾。随后 `Vec` 箱子装着三张长寿卡片，整体缩成短寿箱子。 | 打字、滑入、绿勾 |
| `v_invariant` 不变 `&mut T` | 打出 `assign` 代码。画面右侧是“内存视图”：`hello` 槽位（金色永生边框）与内层作用域里的 `world`。慢镜头演示“假如协变”：`&world` 被写入 `hello` → 作用域结束，`world` 化为碎片 → `hello` 的箭头指向一片废墟（灰色裂纹）。画面一闪，回到第一章的“猫笼塞狗”爆炸缩略图，两者并排。rustc 机器人亮红灯，打出真实报错 `E0597`。 | 慢动作低频、碎裂、回忆的倒带声、错误嗡鸣 |
| `v_contravariant` 逆变 `fn(T)` | 两台函数机器：宽入口的 `fn(&'short str)` 和窄入口的 `fn(&'static str)`。`'static` 卡片轻松塞进宽入口（✓）；反过来短命卡片卡在窄入口外（✗）。上下两条子类型箭头方向相反地闪烁。 | 机器咔嗒、通过与卡住的音效 |
| `v_bivariant` 双变与 PhantomData | `struct Foo<T> { x: i32 }` 中 `T` 像幽灵一样半透明飘着，rustc 报 `E0392`。幽灵被装进 `PhantomData<…>` 的玻璃瓶，三个瓶子分别贴上 `+`、`−`、`o` 标签。 | 幽灵的“呜”、瓶塞“啵” |
| `v_cheatsheet` 口诀与速查表 | 口诀四句逐句亮起，随后展开一张完整速查表（`&'a T`、`&'a mut T`、`Box/Vec`、`Cell`、`fn(T)->U`、`*const/*mut`、`PhantomData`），每行的型变徽章依次点亮。 | 节拍感的“叮叮叮叮”、快门声 |

### 第五章 · 走进 rustc：编译器如何判断型变（约 130s）

| 场景 | 画面 | 音效 |
| --- | --- | --- |
| `c_intro` 推断，而不是标注 | 镜头推进 rustc 机器人的胸口舱门，门打开，进入一个满是齿轮和传送带的“车间”。 | 舱门气压声、齿轮转动 |
| `c_lattice` 型变之格 | 一个菱形格：底部双变 `*`，左右协变 `+` 与逆变 `−`，顶端不变 `o`。小球从底部往上爬，演示“合并取上界”：`+` 和 `−` 合并，小球升到 `o`。 | 上行音阶 |
| `c_walk` 逐个字段收集约束 | 传送带送来 `struct Demo<'a, 'b, T, U>` 的三个字段，每个字段进入扫描仪后，右侧约束表对应格子点亮徽章；`T` 的两个徽章 `+` 与 `−` 在格上相遇并升到 `o`。 | 扫描仪“哔哔”、格子点亮 |
| `c_xform` 位置的乘法 | 一张 4×4 的“乘法表”逐格亮起；然后 `fn(fn(T))` 被一层层剥开，两个蓝色 `−` 相乘变成绿色 `+`。 | 计算器按键、负负得正的“叮咚” |
| `c_fixpoint` 不动点 | `struct List<'a, T, U>` 的 `next` 字段指回自己，型变表一轮轮迭代，数值稳定后锁定（锁扣声）。一个只在递归里出现的参数 `U` 始终停在紫色 `*`，被红框圈出，弹出真实报错 `type parameter U is only used recursively`。 | 循环的嗡鸣、锁扣、错误音 |
| `c_use` 型变表的用途 | 型变表被送进“类型比较器”：协变走同向通道、逆变走反向通道、不变要求两边贴合。生命周期约束被打包送往一个盾牌形状的“借用检查器”。rustc 屏幕上打出 `#[rustc_variance]` 与输出 `['a: +, 'b: +, T: o, U: o]`。 | 传送、盾牌“铛” |

## 技术实现概要

- `src/script.js`：唯一的文案来源（字幕 / 配音 / 文档）。
- `src/engine.js`：时间轴、缓动、SVG 工具；每个场景的画面都是“时间 t 的纯函数”，因此可以任意拖动进度条、逐帧导出视频。
- `src/audio.js`：WebAudio 合成音效与背景音乐、配音播放（预生成音频优先，浏览器朗读兜底）。
- `src/characters.js`：Claude、Ferris、rustc、猫、狗等角色，带眨眼、说话口型、情绪。
- `src/widgets.js`：代码面板（含 Rust 语法高亮与打字机效果）、箭头、徽章、笼子、光带、格等。
- `src/scenes/*.js`：各章节场景。
- `tools/`：导出文案、生成配音、导出 MP4 的脚本。
