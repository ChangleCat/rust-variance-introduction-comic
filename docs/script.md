| --- | --- | --- | --- |

| 2 | Claude | 往上走，约束越来越强。两个结论合并时，就取它们在格上的上界。 |  |
| 3 | Claude | 每个泛型参数，一开始都被假定为双变，也就是还没有任何约束。 |  |

### 逐个字段收集约束 `c_walk`（约 18 秒配音）

| # | 角色 | 台词 | 朗读 |
| --- | --- | --- | --- |
| 1 | Claude | 然后，编译器逐个检查字段，看每个参数出现在什么位置。 |  |

### 位置的乘法 `c_xform`（约 16 秒配音）

| # | 角色 | 台词 | 朗读 |
| --- | --- | --- | --- |
| 1 | Claude | 嵌套的类型怎么办？位置的型变，会像正负号相乘一样组合。 |  |
| 2 | Claude | 协变乘任何东西都不改变它；逆变乘逆变，负负得正；碰到不变，结果就是不变。 |  |
| 3 | Claude | 比如 fn(fn(T)) 里的 T，被翻转了两次，反而是协变的。 | 比如函数参数里再套一个函数参数，T 被翻转了两次，反而是协变的。 |
